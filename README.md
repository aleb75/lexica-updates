# Lexica updates

Public update feed for the Lexica Windows app. A friend does not need a GitHub account.

Lexica looks here:

https://github.com/aleb75/lexica-updates/releases/latest/download/latest.json

Each release should contain:

- `latest.json` — version, pack id, checksum, and download name
- `lexica-ui.zip` — the UI pack (`index.html` at the zip root)

Only those files belong here. Do not store secrets or personal study data.
